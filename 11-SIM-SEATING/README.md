# SIM detection

There is no software patch for this item.

The S13 SIM/RIL problem was resolved by physically reseating the nano-SIM so it sat flat and made proper contact. After correct seating, the device moved from ABSENT / SIM REMOVED to a loaded SIM with a readable ICCID.

If SIM detection fails on another S13, verify physical seating before changing modem/RIL software.
