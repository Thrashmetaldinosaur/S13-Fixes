# S13 Circle Scale v1.1

Package: `com.s13.circlescale`

LSPosed module pulled from the live watch.

Purpose:
- Applies the S13's circle-mode app scaling through the System Framework.
- Reads `watch_small_screen_stat`.
- Uses the `s13_circle_scale_percent` setting when configured.

Install:
1. Install the APK.
2. Enable it in LSPosed.
3. Scope it to Android System Framework (`android`).
4. Reboot.
